## Data Flow Diagram

```
┌─────────────────────────────────────────────────────────────────────┐
│                        USER INTERACTION                              │
└───────────────────────────────┬─────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────────┐
│                     AUTHENTICATION LAYER                             │
├─────────────────────────────────────────────────────────────────────┤
│  1. Validate Credentials       ────────►  Supabase Auth             │
│  2. Fetch User Profile         ────────►  PostgreSQL Database       │
│  3. Verify Admin Role          ────────►  RBAC Check                │
│  4. Check Account Status       ────────►  Status Validation         │
└───────────────────────────────┬─────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────────┐
│                      AUTHORIZATION LAYER                             │
├─────────────────────────────────────────────────────────────────────┤
│  1. Load User Permissions      ────────►  RBAC Utilities            │
│  2. Filter Available Views     ────────►  canAccessView()           │
│  3. Check Feature Permissions  ────────►  hasPermission()           │
└───────────────────────────────┬─────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────────┐
│                      APPLICATION LAYER                               │
├─────────────────────────────────────────────────────────────────────┤
│  1. Render Sidebar             ────────►  Role-based Menu           │
│  2. Display Dashboard          ────────►  Filtered Data             │
│  3. Show Action Buttons        ────────►  Permission Check          │
│  4. Filter Queue Data          ────────►  Role-based Filtering      │
└───────────────────────────────┬─────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────────┐
│                         DATA LAYER                                   │
├─────────────────────────────────────────────────────────────────────┤
│  1. Fetch Requests             ────────►  Database Query            │
│  2. Apply RLS Policies         ────────►  PostgreSQL RLS            │
│  3. Filter by Role             ────────►  Application Logic         │
│  4. Return Allowed Data        ────────►  User Interface            │
└─────────────────────────────────────────────────────────────────────┘
```
